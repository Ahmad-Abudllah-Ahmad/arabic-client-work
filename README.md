# Al Hassan Coffee — Arabic Client Store

Static multi-page storefront (HTML, CSS, JavaScript) for Al Hassan Coffee: hero slider, product catalog, cart, checkout demo, and AI chatbot assistant.

## Deploy on Vercel

1. Push this repository to GitHub.
2. In [Vercel](https://vercel.com), **Add New Project** → import `arabic-client-work`.
3. Framework preset: **Other** (static site). Build command: leave empty. Output directory: `.` (root).
4. Deploy. `index.html` is served at `/`.

No build step required.

## Local preview

```bash
npx serve .
```

Open `http://localhost:3000`.
